## **Assignments Overview**

### **Assignment 1 (STQAAssignment1) – Gmail Login Page Testing**

**Objective:**

* Write Selenium automation scripts for Gmail login page.
* Implement positive and negative test scenarios.

**Code File:**

* `LoginTest.java`

**Functionalities Tested:**

1. Valid login (positive test)
2. Invalid login (negative test)
3. Field validations (blank username/password, invalid characters, etc.)

**Software Required:**

* Eclipse IDE (Java & Web Developers version recommended)
* Java JDK 17+
* Selenium WebDriver 4.x
* Chrome browser & ChromeDriver
* XAMPP (for local HTML login page)

**Folder & File Structure:**

```
STQAAssignment1/
 ├─ src/
 │   └─ com/sppu/LoginTest.java
 ├─ index.html
 ├─ login.php
 ├─ chromedriver.exe
 └─ README.md
```

**Steps to Run:**

1. Install Java JDK 17+ and add it to PATH.
2. Install Eclipse IDE (Java & Web Developers).
3. Add Selenium JARs or use Maven dependency.
4. Place `chromedriver.exe` in the project folder.
5. Run `LoginTest.java` as **Java Application**.
6. Check console output for login test results.

**Practical Submission Proof:**

* HTML login page (`index.html` & `login.php`)
* Java code (`LoginTest.java`)

### **Assignment 2 (STQAAssignmentno2) – Excel Test Case Writing**

**Objective:**

* Write Java code to generate an Excel sheet with test cases for a social media application.

**Code File:**

* `CreateWriteExcelFile.java`

**Functionalities Implemented:**

1. Create Excel sheet with header row: Test Case ID, Scenario, Input, Expected Result, Actual Result, Status
2. Insert example positive login test case

**Software Required:**

* Eclipse IDE (Java Developers or Java & Web Developers)
* Java JDK 17+
* JExcelAPI (`jxl.jar`) **or Maven with JXL dependency**

**Folder & File Structure:**

```
STQAAssignmentno2/
 ├─ src/main/java/com/sppu/CreateWriteExcelFile.java
 ├─ pom.xml         (if using Maven)
 ├─ TestCases.xls   (generated by program)
 └─ README.md
```

**Maven Dependency for JXL:**

```xml
<dependency>
    <groupId>net.sourceforge.jexcelapi</groupId>
    <artifactId>jxl</artifactId>
    <version>2.6.12</version>
</dependency>
```

**Steps to Run:**

1. Install Java JDK 17+ and add to PATH.
2. Install Eclipse IDE.
3. Create Maven project `STQAAssignment2` (or standard Java project with `jxl.jar` added to Build Path).
4. Copy `CreateWriteExcelFile.java` into `src/main/java/com/sppu/`.
5. Run the Java class as **Java Application**.
6. Check `TestCases.xls` at path `D:\BE Practicals\STQA\STQAAsignment2\TestCases.xls`.

**Practical Submission Proof:**

* Excel file with test cases (`TestCases.xls`)
* Java code (`CreateWriteExcelFile.java`)

### **Notes / Tips**

1. Always match **ChromeDriver version** with Chrome browser.
2. For Windows paths in Java, **use `\\` or `/`** in file paths.
3. Use **Maven** to avoid manual JAR management — it simplifies builds.
4. Make sure **package names match folder structure** (e.g., `com.sppu`).
5. For practical submission, include: Java code, generated Excel, HTML/PHP files, and console screenshots.

## **Assignments Overview**

### **Assignment 1 (STQAAssignment1) – Gmail Login Page Testing**

**Objective:**

* Write Selenium automation scripts for Gmail login page.
* Implement positive and negative test scenarios.

**Code File:**

* `LoginTest.java`

**Functionalities Tested:**

1. Valid login (positive test)
2. Invalid login (negative test)
3. Field validations (blank username/password, invalid characters, etc.)

**Software Required:**

* Eclipse IDE (Java & Web Developers version recommended)
* Java JDK 17+
* Selenium WebDriver 4.x
* Chrome browser & ChromeDriver
* XAMPP (for local HTML login page)

**Folder & File Structure:**

```

STQAAssignment1/
├─ src/
│   └─ com/sppu/LoginTest.java
├─ index.html
├─ login.php
└─ chromedriver.exe

```

**Steps to Run:**

1. Install Java JDK 17+ and add it to PATH.
2. Install Eclipse IDE (Java & Web Developers).
3. Add Selenium JARs or use Maven dependency.
4. Place `chromedriver.exe` in the project folder.
5. Run `LoginTest.java` as **Java Application**.
6. Check console output for login test results.

**Practical Submission Proof:**

* HTML login page (`index.html` & `login.php`)
* Java code (`LoginTest.java`)

### **Assignment 4 (STQAAssignment4) – Selenium Grid & WebDriver Setup**

**Objective:**

* Install and configure Selenium Grid and Selenium WebDriver with Java Eclipse.
* Execute basic automation scripts on multiple browsers.

**Code File (Example):**

* `SeleniumGridTest.java`

**Functionalities Implemented:**

1. Setup Selenium Hub and Nodes for parallel testing.
2. Run WebDriver scripts to open a web page and print the title.
3. Demonstrate browser-specific automation (Chrome, Firefox, Edge).

**Software Required:**

* Java JDK 17+
* Eclipse IDE (Java & Web Developers)
* Selenium WebDriver 4.x
* Chrome, Firefox, Edge browsers
* Browser drivers (chromedriver.exe, geckodriver.exe, msedgedriver.exe)
* Selenium Server Standalone Jar (`selenium-server-4.x.jar`)

**Folder & File Structure:**

```
STQAAssignment4/
 ├─ src/main/java/com/sppu/SeleniumGridTest.java
 ├─ selenium-server-4.x.jar
 ├─ chromedriver.exe
 └─ README.md
```

**Steps to Run:**

1. Install Java JDK 17+ and add to PATH.
2. Install Eclipse IDE.
3. Download Selenium WebDriver and Browser Drivers.
4. Start Selenium Grid Hub:

   ```
   java -jar selenium-server-4.x.jar hub
   ```
5. Register Nodes to Hub:

   ```
   java -jar selenium-server-4.x.jar node --detect-drivers
   ```
6. Copy `SeleniumGridTest.java` into Eclipse project and run as **Java Application**.
7. Observe browser automation output (title printed in console).

**Practical Submission Proof:**

* Java code (`SeleniumGridTest.java`)
* Console output showing page titles
* Screenshot of running Selenium Grid Hub and Nodes

### **Notes / Tips**

1. Always match **BrowserDriver version** with installed browser.
2. For Windows paths in Java, **use `\\` or `/`** in file paths.
3. Use **Maven** to avoid manual JAR management — simplifies builds.
4. Ensure **package names match folder structure** (e.g., `com.sppu`).
5. Include **Java code, generated files, and console outputs** for practical submission.
